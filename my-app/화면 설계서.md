# 링크 인 바이오 서비스 화면 설계서

## 1. 프로젝트 개요

기업 서비스 링크를 하나의 페이지에 모아 제공하는 **Hyundaecorp Link-in-Bio 서비스**를 제작한다.

방문자는 하나의 URL을 통해 회사 프로필과 주요 서비스 배너를 확인할 수 있으며, 각 배너를 클릭하면 해당 분석 서비스로 이동한다.

### 핵심 목표

- 최대한 단순하고 직관적인 UI
- 세련되고 현대적인 디자인
- Apple 제품/서비스를 연상시키는 절제된 디자인
- 모바일 사용성을 최우선으로 고려
- 불필요한 장식이나 복잡한 UI를 배제
- 링크와 프로필 정보가 한눈에 들어오는 구조
- 기업 브랜드(로고·서비스)가 명확히 드러나는 구조

---

# 2. 디자인 컨셉

### 키워드

**Simple · Modern · Elegant · Minimal**

### 디자인 방향

Apple 스타일의 미니멀한 디자인을 기반으로 한다.

- 넓은 여백
- 깔끔한 레이아웃
- 과도한 그림자 사용 금지
- 얇고 섬세한 Border
- 높은 가독성
- 단순한 흑백 계열 색상
- 콘텐츠 중심의 UI
- 둥근 모서리를 적절하게 사용
- 배경에는 세로 막대 Crest Wave 애니메이션만 허용

전체적인 인상은 **"기업 브랜드 페이지와 서비스 허브를 결합한 듯한 느낌"**으로 한다.

# 3. 반응형 설계

## Mobile First

모바일을 기준으로 UI를 먼저 설계한다.

### 주요 모바일 기준

- 320px ~ 430px: 최적화
- 375px 기준으로 가장 자연스럽게 보이도록 설계
- 화면 좌우에 적절한 Padding 적용
- 링크 버튼은 화면 폭을 충분히 활용
- 터치 영역을 충분히 확보

### Desktop

Desktop에서는 콘텐츠가 화면 전체로 퍼지지 않도록 중앙에 고정된 최대 너비를 가진다.

권장 구조:

```text
┌─────────────────────────────────────────────┐
│                                             │
│                 페이지 영역                 │
│                                             │
│             ┌───────────────┐               │
│             │   콘텐츠      │               │
│             │   최대 480px   │               │
│             └───────────────┘               │
│                                             │
└─────────────────────────────────────────────┘
```

Desktop에서도 모바일 페이지를 확대해 놓은 듯한 느낌이 아니라, 충분한 여백을 가진 독립적인 브랜드 페이지처럼 보여야 한다.

# 5. Header / Theme Toggle

화면 우측 상단에 Dark / Light Theme 전환 버튼을 배치한다.

### 위치

```text
                              ☀
```

화면 우측 상단에 작고 깔끔하게 배치한다.

### 동작

Light Mode ↔ Dark Mode를 클릭 한 번으로 변경한다.

### 초기 상태

**다크 모드를 기본값으로 사용한다.**

- 저장된 테마가 없으면 → Dark Mode
- 사용자가 직접 변경한 경우에는 사용자의 선택(localStorage)을 우선한다.

### 아이콘

Light Mode:

- Moon 아이콘

Dark Mode:

- Sun 아이콘

아이콘은 Lucide 계열의 단순한 Outline 아이콘 스타일을 사용한다.

# 6. Profile 영역

페이지 상단 중앙에 프로필 정보를 배치한다.

## 구성

```text
      ┌────────────────────┐
      │                    │
      │   HYUNDAE 로고     │
      │                    │
      └────────────────────┘

         Hyundaecorp

          AI website

   배너 클릭시 해당 링크로 이동됩니다.
```

### 프로필 이미지(로고)

- **둥근 사각형(rounded rectangle)** 형태
- 가로형 로고가 잘리지 않도록 `object-contain` 적용
- 권장 크기: **약 160 × 88px**
- 이미지 경로: `/avatar.png`
- 이미지 로드 실패 시 이니셜 Avatar(`H`) 표시

원형 Avatar는 사용하지 않는다. 로고 전체가 보이도록 사각형 프레임을 유지한다.

### 이름

`Hyundaecorp`

- 가장 중요한 텍스트 중 하나
- Semibold
- 큰 글자 크기 (**약 26px**)

### 타이틀

`AI website`

- 이름보다 작게
- Medium
- Subtle한 색상 (**약 15px**)

### 소개

`배너 클릭시 해당 링크로 이동됩니다.`

- 짧고 간결하게 표시
- 타이틀보다 조금 더 연한 색상
- 중앙 정렬 (**약 14px**)

# 7. Link Button 영역

프로필 영역 아래에 링크 버튼을 세로로 배치한다.

### 링크 목록

1. 검사DATA분석
2. 생산DATA 분석

### 버튼 형태

세로형 풀폭 버튼을 사용한다.

```text
┌──────────────────────────────────┐
│                                  │
│   [Icon]       검사DATA분석       │
│                                  │
└──────────────────────────────────┘
```

모든 버튼의 크기와 구조는 동일하게 유지한다.

### 버튼 스타일

Light Mode:

- White 또는 아주 옅은 배경
- 얇은 Border
- 검정 계열 텍스트
- 미세한 Shadow

Dark Mode:

- 매우 어두운 Gray 계열 배경
- 얇은 밝은 Border
- 흰색 계열 텍스트
- Shadow 없음

### 권장 형태

- Width: 100%
- Height: 약 56px (`h-14`)
- Border Radius: 16px (`rounded-2xl`)
- 좌우 Padding: 20px

### 아이콘

각 서비스에 맞는 Outline 아이콘을 사용한다.

```text
[차트/분석 아이콘]  검사DATA분석
[공장/생산 아이콘]  생산DATA 분석
```

- 아이콘은 버튼 왼쪽 고정 영역에 배치
- 텍스트는 버튼 중앙 정렬

---

# 8. Link Button Interaction

링크 버튼에 Hover 또는 Touch Interaction을 적용한다.

### Desktop Hover

마우스를 올렸을 때:

- 배경색이 아주 미세하게 변경
- Border 색상 변화
- 약간의 상승 이동

권장:

```text
transition: all 0.2s ease;
transform: translateY(-1px);
```

### Mobile

Touch 시 버튼이 살짝 눌리는 느낌(`scale` 미세 감소)을 제공한다.

# 10. 배경 — Crest Wave Animation

페이지 전체 배경에 세로 방향 그라데이션 막대 애니메이션을 적용한다.

### 구조

- 약 **18개**의 세로 막대(`crest-bar`)를 화면 전체 너비로 배치
- 각 막대 안에 빛나는 정점선(`crest-glow`)이 세로로 흐름
- 막대별 `animation-delay`를 다르게 주어 **V자 모양의 물결**을 형성

### 동작

- 빛나는 선이 V자 형태를 유지한 채 위에서 아래로 반복 이동
- 애니메이션 주기: 약 **9초**
- `prefers-reduced-motion: reduce`일 경우 애니메이션 비활성화

### 색상

| 모드 | 정점선 색 |
|---|---|
| Dark | 밝은 흰색 (`rgba(255, 255, 255, 0.92)`) |
| Light | 차분한 차콜 그레이 (`rgba(72, 72, 78, 0.45)`) |

배경은 `position: fixed`로 전체 화면에 깔리고, 콘텐츠는 `z-index`로 위에 올린다.
배경은 `pointer-events: none`으로 클릭을 방해하지 않는다.

# 11. Light Theme

Light Theme은 Apple 스타일의 깔끔한 화이트 기반 디자인으로 구성한다.

### 기본 색상

| 토큰 | 값 |
|---|---|
| Background | `#f5f5f7` |
| Foreground | `#1d1d1f` |
| Secondary Text | `#6e6e73` |
| Muted Text | `#86868b` |
| Surface | `#ffffff` |
| Border | `#d2d2d7` |
| Crest Peak | 차콜 그레이 |

색상은 많이 사용하지 않는다. **전체 UI는 흑백 계열을 중심으로 구성한다.**

# 12. Dark Theme

Dark Theme을 **기본 테마**로 사용한다.

### 기본 색상

| 토큰 | 값 |
|---|---|
| Background | `#0b0b0c` |
| Foreground | `#f5f5f7` |
| Secondary Text | `#a1a1a6` |
| Muted Text | `#6e6e73` |
| Surface | `#161618` |
| Border | `#2c2c2e` |
| Crest Peak | 밝은 흰색 |

순수한 `#000000`만 사용하는 것보다 아주 약간의 Gray를 섞어 깊이감을 준다.

# 13. Typography

전체적으로 시스템 폰트를 우선 사용한다.

한국어 가독성을 고려하여 적절한 시스템 Sans-serif 폰트를 사용한다.

### Typography hierarchy

```text
이름 (Hyundaecorp)
26px / Semibold

타이틀 (AI website)
15px / Medium

소개
14px / Regular

링크 버튼
15px / Medium
```

텍스트가 많지 않기 때문에 **폰트 크기와 여백을 활용하여 고급스러운 느낌을 만드는 것**을 우선한다.

---

# 14. Spacing

전체 페이지는 넉넉한 여백을 사용한다.

특히:

- Profile과 Link 영역 사이
- Link 버튼 사이 (`gap-3`)
- 상단/하단 Padding

에 충분한 여백을 준다.

단, 모바일에서 스크롤이 지나치게 길어지지 않도록 한다.
문의 FAB가 없으므로 하단 Padding은 FAB용 여백(`pb-28`) 없이 일반 여백(`pb-10`)을 사용한다.

---

# 15. Animation 원칙

애니메이션은 절제하되, 배경 Crest Wave는 의도적으로 허용한다.

### 적용 대상

- Crest Wave 배경 (세로 정점선 흐름)
- Link Button Hover
- Link Button Press
- Theme Change

### 적용하지 않는 것

- 과도한 Parallax
- 장식용 Bounce
- 복잡한 페이지 전환
- 콘텐츠를 가리는 강한 움직임

전체적인 철학은:

> **"배경은 분위기를 만들고, 콘텐츠 Interaction은 미세하게만 반응한다."**

---

# 16. 접근성

기본적인 접근성을 반드시 고려한다.

### 필수 사항

- 모든 링크/버튼에 명확한 의미 제공
- 아이콘만 사용하는 버튼에는 `aria-label` 제공
- 충분한 색상 대비
- Focus 상태 제공
- 모바일에서 최소 터치 영역 확보
- `prefers-reduced-motion` 대응

# 17. 전체 사용자 흐름

## 방문자

```text

   ↓
```

# 18. 최종 화면 우선순위

화면에서 사용자가 가장 먼저 인식해야 하는 순서는 다음과 같다.

```text
1. 기업 로고
        ↓
2. 이름 (Hyundaecorp)
        ↓
3. 타이틀 / 안내 문구
        ↓
4. 서비스 링크 배너
```

따라서 장식적인 요소보다 **프로필 → 서비스 링크**의 정보 구조가 명확하게 전달되도록 디자인한다.

---

# 19. 최종 디자인 원칙

이 서비스의 디자인을 구현할 때 다음 원칙을 반드시 지킨다.

1. 최대한 심플하게 만든다.
2. Apple 스타일의 절제된 디자인을 지향한다.
3. 흑백을 중심으로 색상을 제한한다.
4. 배경 Crest Wave 외의 불필요한 장식 요소를 넣지 않는다.
5. 여백을 충분히 사용한다.
6. 링크 버튼은 동일한 디자인 시스템을 유지한다.
7. 모바일을 최우선으로 한다.
8. Desktop에서는 콘텐츠 최대 너비를 제한한다.
9. 콘텐츠 Interaction 애니메이션은 미세하게만 사용한다.
10. 문의하기 FAB / Modal은 제공하지 않는다.
11. Dark Mode를 기본으로 하고, Light Mode와 동일한 정보 구조를 유지한다.
12. 사용자가 페이지에 들어왔을 때 3초 이내에 "어떤 브랜드인지"와 "어디로 이동할 수 있는지"를 이해할 수 있어야 한다.

# 20. AI 구현 시 중요 지시사항

이 화면 설계서를 기반으로 실제 UI를 구현할 때는 단순히 기능을 구현하는 것보다 **시각적인 완성도와 여백, 타이포그래피, 반응형 디자인을 중요하게 고려한다.**

특히 다음을 피한다.

- 기본 HTML 버튼처럼 보이는 UI
- 과도한 Shadow
- 지나치게 둥근 버튼
- 불필요한 Card 남발
- 복잡한 Navigation
- Crest Wave 외의 장식적인 배경
- 과도한 Bounce 애니메이션
- 모바일에서 너무 넓은 콘텐츠 영역
- 서로 다른 버튼 스타일의 혼용
- 원형으로 로고를 잘라 일부만 보이게 하는 처리
- 문의하기 FAB / Modal 재도입

최종 결과물은 **기업 서비스 링크를 모아놓은 단순한 페이지이지만, 완성도 높은 브랜드 허브 페이지처럼 느껴져야 한다.**

전체적인 디자인은 **Apple의 미니멀함 + Hyundaecorp 서비스 허브**를 목표로 한다.
